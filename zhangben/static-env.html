这个版本是什么

用于演示与本地试用，不连接任何服务器

  • 页面由 HTML / CSS / JS 静态文件组成，通过本机 HTTP 服务打开即可使用，不需要数据库或后端接口。
  • 所有装修数据（预算、账单、待办、采购、日记、比价、流程节点、验收记录）都保存在当前浏览器的 localStorage，键名前缀为 xzreplica.。
  • 登录为本机模拟：账号信息存在 zhangben_users，登录状态存在 zhangben_session，不进行服务器校验。
  • 数据不会上传到任何服务器，也不会与其他设备共享。

备份与迁移

换设备、换浏览器或清理缓存前，请先导出备份

  • 账号管理页「导出数据」：导出带 xzreplica. 前缀的完整备份 JSON。
  • 首页「导出备份」：导出无前缀键名的备份 JSON。
  • 两种格式可以互相导入，导入时会覆盖本机同类数据。
  • 导入后可在首页核对预算、账单、采购与比价是否与导出前一致。
去账号管理导出 去首页导出备份

清理浏览器数据、切换浏览器或使用隐私模式，都会让本机数据消失且无法恢复，请务必保留导出的 JSON 文件。

使用建议与已知限制

按以下方式使用体验最好

  • 建议使用最新版 Chrome / Edge，通过 HTTP 地址访问；直接双击以 file:// 打开时，部分页面脚本可能无法正常加载。
  • 本机存储容量通常为 5–10 MB，日记照片会自动压缩；空间不足时页面会提示保存失败，请先导出备份再清理旧数据。
  • 客户端项目页的装修公司、照片均为演示数据，可按实际公司信息手动修改。
  • 计算器的算法与原版一致，最近一次输入与房间列表会保存在本机，刷新后可恢复；瓷砖排版工具为申请制，静态版不提供排版画布。
  • 登录页预置的演示账号（15668681555@163.com）在首次访问时自动生成，账号密码以明文保存在本机 localStorage，请勿在本演示环境使用真实密码。
  • 对外部署前，在登录页引入 window.__XZ_DEMO__ = false 并清空本机 zhangben_users，即可不再生成演示账号；已注册账号不受影响。
  • 首页“数据备份”支持导出/导入 JSON；“恢复上一版”可回滚最近一次写入前的本机内容（最多保留 3 份），误删或误清空时可先用它找回。

如果只需要查看界面与流程，使用本机演示数据即可；如需长期记录真实装修支出，请定期导出备份，或使用线上正式版账号同步。
